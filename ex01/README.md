# Exercício: Criar um Website Utilizando Eventos em PowerShell

- O objetivo desse exercício é utilizar do `PowerShell` para criar automaticamente um site responsivo e interativo.

```
├── 📁 TechConnect2026
│   ├── 📁 scripts
│   │   └── 📄 countdown.js
│   ├── 📁 styles
│   │   └── 🎨 main.css
│   └── 🌐 index.html
├── 📝 README.md
├── 📄 setup_event.ps1 # Script para rodar em Windows
└── 📄 setup_event.sh  # Script para rodar em MacOS
```

## Observação para o script no Windows

> Caso haja alguma restrição de scripts no PowerShell, execute o comando a seguir: <br>
> `Set-ExecutionPolicy RemoteSigned -Scope CurrentUser`

##

## Rodando o script no MacOS

1. Abra o Terminal do macOS (você pode usar a busca do Spotlight pressionando `Cmd + Espaço` e digitando "Terminal").

2. Navegue até a pasta onde você salvou o arquivo `setup_event.sh` (usando o comando `cd`).

3. Dê permissão de execução ao script com o comando: `chmod +x setup_event.sh`.

4. Execute o script com: `./setup_event.sh`.
