# Avaliação P1: Projeto - Ferramentas de IA

- O Projeto Ferramentas de IA em Destaque visa criar um sistema simples para estudantes, professores e funcionários visualizarem informações sobre as Inteligências Artificiais populares e suas funcionalidades. O sistema terá duas telas principais: a Tela Inicial (Catálogo de IAs) e a Tela de Detalhes.

## Observação para o funcionamento correto do projeto

1. Na pasta raiz dê o comando: `python -m venv .venv`

2. Lembre-se de estar na pasta raiz do projeto, e de rodar o seguinte comando para ativar o ambiente virtual: <br>
> `source .venv/bin/activate` - Para dispositivos MacOS <br>
> `\.venv\Scripts\activate` - Para dispositivos Windows

3. Em seguida, dê o comando: `pip install flask`.

4. Para executar o projeto, dê o comando no `flask run` no terminal, e pronto.
